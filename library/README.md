# BLITZ SLAYER V2 — Library Folder

Put your audio files here.

## Folder structure
- `library/audio/music/` (background tracks, looped)
- `library/audio/sfx/` (sound effects)

Empty folders are preserved using `.keep` files. You can ignore or delete them.

## Recommended music filenames
Put these in `library/audio/music/`:
- `start.mp3` (menu / before battle)
- `battle.mp3` (during battle)
- `end_win.mp3`
- `end_lose.mp3`
- `end_draw.mp3`

## Recommended sfx filenames
Put these in `library/audio/sfx/`:
- `ui_click.wav`
- `card_select.wav`
- `card_play.wav`
- `beam.wav`
- `hit.wav`
- `miss.wav`
- `scan.wav`
- `repair.wav`
- `move.wav`
- `shield.wav`
- `jam.wav`
- `reboot.wav`
- `malware.wav`
- `turn_ai.wav`
- `turn_player.wav`
- `win.wav`
- `lose.wav`
- `draw.wav`

Notes:
- If a file is missing, the game will stay silent for that event (no crashes).
